Continuous Reward-Driven Learning in Spiking Neural Networks for Embedded Event-Based Robot Control

Nicola Russo; Konstantin Nikolic

This paper presents a reward-based spiking neural network (SNN) for a robotic agent driven by real-time visual input from a Dynamic Vision Sensor (DVS) and reward feedback from a touch sensor. The approach is demonstrated in a robotic goalkeeper scenario in which the agent must learn autonomously how to block an approaching ball. The learning process is organised around two linked objectives: (1) developing an internal representation of the visual input, and (2) selecting an appropriate response on the basis of that input and subsequently applying reinforcement learning through feedback from the touch sensor. The proposed architecture combines an unsupervised input-hidden stage, trained with Spike-Timing-Dependent Plasticity (STDP), lateral inhibition, and adaptive thresholds, with a reward-modulated hidden-output stage based on eligibility traces and delayed reinforcement. This separation enables the network first to self-organise sparse internal encodings of ball trajectories and then to refine the sensorimotor mapping through reward feedback. The full perception-to-action loop is deployed on a Raspberry Pi 5, avoiding specialised neuromorphic accelerators while preserving the temporal structure of event-based sensing. The study examines how internal event representations can be learnt for action and remain adaptable after deployment. The result is a compact neuromorphic control pipeline relevant to current work on continual learning, embedded autonomy, and representation learning for event-based robotics.
